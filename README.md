# 🧠 Personal Knowledge Vault

A modern and responsive landing page for **Personal Knowledge Vault**, a concept designed to help learners organize notes, links, and learning summaries in a structured way.

The website focuses on creating a clear and organized learning experience where knowledge can be captured, connected, and revisited easily.

## 🌐 Live Demo

🔗 **Live Website:** https://achol-jahan.github.io/B13-A1/

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts

  * Inter
  * Open Sans

## ✨ Main Features

* 📚 Structured knowledge and note-taking concept
* 🔗 Organized learning resources and links
* 🧠 Personal knowledge vault concept
* 🔍 Semantic search concept
* 💡 Reflection and learning prompts
* 📱 Clean and modern landing-page design
* 🎨 Custom UI with responsive design principles
* 🚀 Early-access call-to-action sections
* 🔗 Social media links in the footer

## 📦 Dependencies & External Resources

This project is primarily built with HTML and CSS.

### External Resources

* **Google Fonts** — Inter & Open Sans
* **Font Awesome 7** — Icons

Font Awesome is loaded through CDN:

```html
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.0.1/css/all.min.css"
>
```

Google Fonts are also loaded through CDN.

## 💻 Run Locally

Follow these steps to run the project on your local machine.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Open the project

You can simply open `index.html` in your browser.

Alternatively, if you use **VS Code**, install the **Live Server** extension and open the project using Live Server.

The website should then be available locally in your browser.
